# Adventure Works Sales Analysis

## Project Overview
A Data Analytics project focused on analyzing sales, products, customers, profitability, and regional performance using multiple data analytics tools.
The project demonstrates the complete analytics workflow, from data preparation and SQL analysis to interactive dashboard development and business insights.

## Tools & Technologies
**Excel** - Data preparation and analysis <br>
**MySQL** - Database management and SQL analysis <br> 
**Power BI** - Interactive dashboard and KPI analysis <br> 
**Tableau** - Data visualization and dashboard development <br>
**PowerPoint** - Project presentation and findings <br>

## Key KPIs
KPIs	& Values
- **Total Sales** - 29.36M
- **Production Cost** - 17.28M
- **Profit** - 12.08M
- **Profit Margin** - 41.15%
- **Total Orders** - 60,398

## Analysis Areas
* Year-wise and month-wise sales analysis 
* Sales vs. production cost
* Profit and profit-margin analysis
* Product performance
* Customer analysis
* Regional sales performance
* Top-performing products and customers
* Interactive dashboard development

## Project Files
File	Description
* **Excel Analysis** - Data preparation and Excel-based analysis
* **SQL Analysis** - MySQL database and SQL queries
* **Power BI Dashboard** - Interactive Power BI dashboard
* **Tableau Dashboard** - Interactive Tableau visualizations
* **Project Presentation** - Detailed project presentation, analysis, insights, challenges and solutions

## Project Objective
The objective of this project is to transform raw sales data into meaningful business insights and demonstrate practical skills in data cleaning, SQL, data visualization, dashboard development, and business analysis.

## Project Outcome
The analysis provides a consolidated view of sales performance, profitability, product and customer trends, and regional performance, helping identify important business trends and areas of performance.
